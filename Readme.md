学校: 电子科技大学   授课老师:王敏

### 作业内容
总体而言是使用不同的方法对一个训练集进行无监督学习, 对两个测试集进行异常检测.
##### 数据集特征:
1. 大小: 三个数据集均是(3999,31). 数据量非常小
2. 每个数据集都是一个时间序列. 
3. 每个测试序列后1999个点是异常点.
4. TestData1容易检测, TestData2不容易检测.
##### 作业具体内容
+ 作业1: 使用马氏距离度量进行异常检测.
+ 作业2: 使用经典PCA进行数据降维和异常检测. 加分项: PCA变体. 我使用PPCA,即概率PCA
+ 作业3: 自行生成3类数据,并使用svm对数据进行分类. 加分项: 使用 One-Class SVM 进行异常检测
+ 作业4: 使用rnn,lstm对数据进行异常检测. 加分项: 使用lstm自编码器进行异常检测
